## Phase 2 — Breaking API redesign

Single commit bundle. Document migration in CHANGELOG.

### 2.1 Context propagation

**Client (low-level RPC):**
```go
// Before
func (c *Client) Read(group, offset, length uint32) ([]byte, error)
func (c *Client) Write(group, offset uint32, data []byte) error
func (c *Client) WriteRead(group, offset, readLen uint32, writeData []byte) ([]byte, error)
func (c *Client) ReadState() (States, error)
func (c *Client) ReadDeviceInfo() (DeviceInfo, error)
func (c *Client) AddDeviceNotification(...) (uint32, error)
func (c *Client) DeleteDeviceNotification(handle uint32) error
func (c *Client) SumRead(requests []SumReadRequest) ([]SumReadResult, error)
func (c *Client) SumWrite(requests []SumWriteRequest) ([]SumWriteResult, error)
func (c *Client) SumAddDeviceNotification(...) ([]SumNotificationResult, error)
func (c *Client) SumDeleteDeviceNotification(handles []uint32) ([]ReturnCode, error)
func (c *Client) GetHandleByName(name string) (uint32, error)
func (c *Client) GetSymbolInfoByName(name string) (Symbol, error)
func (c *Client) GetSymbolVersion() (uint8, error)
func (c *Client) GetSymbolUploadInfo() (SymbolUploadInfo, error)
func (c *Client) DownloadDataTypes(length uint32) ([]byte, error)
func (c *Client) DownloadSymbolList(length uint32) ([]byte, error)
func (c *Client) DownloadInChunks(...) ([]byte, error)
func (c *Client) ReadProcess* / WriteProcess* / ClearProcess*

// After — ctx as first arg
func (c *Client) Read(ctx context.Context, group, offset, length uint32) ([]byte, error)
// ... etc for all RPC methods
```

**Session (symbol-aware):**
```go
// Before
func (sess *Session) ReadFromSymbol(name string) (string, error)
func (sess *Session) WriteToSymbol(name string, value string) error
func (sess *Session) ReadMultipleSymbols(names []string) (map[string]string, error)
func (sess *Session) WriteMultipleSymbols(values map[string]string) (map[string]ReturnCode, error)
func (sess *Session) AddSymbolNotification(...) error
func (sess *Session) AddSymbolNotifications(...) ([]NotificationResult, error)
func (sess *Session) DeleteDeviceNotification(handle uint32) error
func (sess *Session) SumDeleteDeviceNotification(handles []uint32) ([]ReturnCode, error)
func (sess *Session) BrowseSymbols(filter string) ([]SymbolBrowseEntry, error)
func (sess *Session) LoadSymbols() error
func (sess *Session) LoadSymbolsSlow(cfg SlowDiscoveryConfig) error
func (sess *Session) RefreshSymbols() error
func (sess *Session) Reconnect() error
func (sess *Session) AddRoute(name, user, pass string) error

// After — ctx first arg
func (sess *Session) ReadFromSymbol(ctx context.Context, name string) (string, error)
// ... etc
```

**Internal plumbing:**
- `c.sendRequest`: replace `context.WithTimeout(c.ctx, requestTimeout)` with `context.WithTimeout(callerCtx, requestTimeout)`.
- `sess.client.Load().X(callerCtx, ...)` everywhere.
- Retry helpers (`readFromSymbolRetry`, `writeMultipleSymbolsRetry`, etc.) accept ctx, honor cancel between attempts.
- Loops in `Reconnect`, `resubscribeNotifications` — check ctx between iterations.

**Est LOC: ~300 signature changes + ~200 in retry/loop plumbing = ~500.**

### 2.2 NewSession redesign

```go
// Before
func NewSession(ip string, port int, target AMSAddress, source AMSAddress,
    callbackIP string, isLocal bool, requestTimeout time.Duration,
    opts ...SessionOption) (*Session, error)

// After
func NewSession(ctx context.Context, remote AMSEndpoint, opts ...SessionOption) (*Session, error)

type AMSEndpoint struct {
    IP    string
    Port  int
    AMS   AMSAddress

// local NetID + port + callbackIP move to options:
WithLocalAMS(addr AMSAddress) SessionOption
WithCallbackIP(ip string) SessionOption
WithLocalMode() SessionOption  // replaces bool flag
```

**Est LOC: ~50 in session.go + ~10 in tests.**

## Risk + mitigations

- **Phase 2 size**: 700-900 LOC single commit is large. Keep Phase 1 commits separate so bisect remains useful.
- **ctx-cancel semantics**: ensure all retry loops bail on ctx cancel, not just timeout. Test with `context.WithCancel` + immediate `cancel()`.
- **Hardware regression**: Phase 1.1 touches reconnect FSM heavily. Run `symbol_version_hardware_test.go` suite against both TC2 and TC3 PLCs before tagging.
- **Symbol unexport blast radius**: external consumers (none yet) would break. Document in migration.
- **AMSEndpoint type name collision**: verify no existing public symbol of that name elsewhere.
